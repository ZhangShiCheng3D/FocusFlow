阻断项必须先解决，App 目标缺失是第一优先。

Xcode Cloud vs 现有 GitHub Actions

两条路都要先补 App 目标。区别：

  • Xcode Cloud：与 App Store Connect 深度集成、TestFlight/自动分发顺滑；但 workflow 只能在 Xcode(macOS)/ASC 网页里配，仓库侧只能放 ci_scripts/ 钩子。需 Mac。
  • GitHub Actions（你已有 app-store-submit.yml + secrets 规划）：跨平台可维护、AI 可改；补好 App 目标后我能在这里把它修到真正可用，且 macOS runner 已验证可跑。

建议：若你更想要 AI 可持续维护的自动化，修复 GitHub Actions 路线性价比更高（我能改+CI 验证）；若你明确要 Xcode Cloud 的 TestFlight 体验，则按下面 Xcode Cloud 步骤、由你在 Mac 上配置。

落地步骤

Phase 0 · 前置（账号/资产）需你

  1. 注册 Apple Developer Program；ASC 创建 App 记录（bundle com.focusflow.app，平台 macOS）。
  2. 生成 Apple Distribution 证书 + "FocusFlow App Store" 描述文件；建 App Store Connect API Key (.p8)。
  3. 决定首版是否保留 FamilyControls/IM 同步（受限授权/第三方依赖，建议首版精简以降低拒审）。

Phase 1 · 加 Xcode App 目标（解除头号阻断）AI可代做(草案) 需你在 Mac 验证

  1. 我可以生成一份 XcodeGen project.yml（把现有 Sources/FocusFlow + Info.plist + entitlements 映射成 type: application 的 macOS 目标 + 单测目标），连同 Xcode Cloud 的 ci_scripts/ 一并提交。
  2. 你在 Mac 上 brew install xcodegen && xcodegen generate → 得到 FocusFlow.xcodeproj，在 Xcode 里跑通 Run/Archive，修签名。
  3. 把免费 3 音的 .aac 真正放进 Resources/（或确认走网络）。
  4. ⚠️ 我无法在 Windows 上运行 xcodegen/xcodebuild，project.yml 只能算草案，必须由你在 Mac 上迭代验证。

Phase 2 · 测试与构建管线 需你(Xcode Cloud) / AI(GH Actions)

  1. Xcode Cloud：Xcode → 选中工程 → Product → Xcode Cloud → Create Workflow；选 App、分支、Archive-macOS action、TestFlight/App Store 分发。仓库放 ci_scripts/ci_post_clone.sh（如需 xcodegen generate）。
  2. 或 GitHub Actions：补好 App 目标后，我把 app-store-submit.yml/submit_app_store.sh 改为对 .xcodeproj archive+export，并由 macOS CI 验证。

Phase 3 · 商店素材 需你

  1. 隐私政策 URL、技术支持 URL；中英描述、关键词；3–5 张截图；分级 4+。

Phase 4 · 提交审核 需你

  1. Archive → 上传（Xcode Organizer / altool / Xcode Cloud 自动）→ ASC 填审核信息（重点解释各权限用途）→ 提交 → 等 1–3 天。

我现在能立刻代做的

  • AI 生成 XcodeGen project.yml 草案（macOS app 目标 + 测试目标，映射现有源码/Info.plist/entitlements），放进仓库分支。
  • AI 写 Xcode Cloud ci_scripts/（post-clone 装 xcodegen 并 generate）。
  • AI 把 app-store-submit.yml + submit_app_store.sh 改造为面向 .xcodeproj（如选 GitHub Actions 路线）。
  • AI 首版精简：移除/隐藏 FamilyControls 宣称、修免费音效"离线"文案，降低拒审与维护风险。

这些都是仓库侧准备，能把你在 Mac 上的工作量降到最低；但 Xcode Cloud workflow 创建、签名、商店素材、提交审核 必须由你在 Mac + Apple 账号侧完成——AI 无法越过这道环境与账号边界。
