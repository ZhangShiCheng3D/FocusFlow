FocusFlow 隐私政策

最后更新：2026-06-22 · Privacy Policy

一句话：FocusFlow 是一款本地优先（Local-First）的菜单栏应用。没有服务器后端、没有账号系统、没有任何分析或追踪 SDK。你的专注数据只存在你自己的 Mac 上，我们（开发者）收集不到、也看不到。

1. 我们不收集什么

FocusFlow 不设自有服务器，不存储任何用户数据于云端。我们不收集你的姓名、邮箱、设备标识、使用行为或专注记录。应用内无任何第三方分析、广告或崩溃追踪 SDK。

2. 数据存在哪里

  • 专注记录与偏好设置：以本地形式保存在你 Mac 的应用沙盒内（系统 UserDefaults），仅存于本机，不上传。
  • 第三方授权令牌：若你主动连接 Slack / Discord / Microsoft Teams，对应的 OAuth 令牌保存在你 Mac 的系统钥匙串（Keychain），仅本机可用。
  • 音效文件：付费音效按需从公开的 GitHub Releases 下载到本地缓存，下载请求不携带任何个人信息。

3. 系统权限的用途

  • 日历（仅写入）：当你开启"自动写入日历 Busy 事件"时，应用在专注时段创建一个标记为忙碌的日程，结束后自动移除。我们只写入，不读取你的任何日程详情。
  • 网络：用于下载音效、以及（当你启用时）OAuth 授权与即时通讯状态同步。

4. 即时通讯状态同步（可选功能）

仅当你主动授权并开启该功能时，FocusFlow 才会在你专注期间，向你已授权的平台（Slack / Discord / Teams）发送一条"专注中"状态文本。OAuth 授权握手经由一个 Cloudflare Workers 中转服务完成，该中转服务不长期存储你的令牌；令牌只保存在你本机的钥匙串中。你可随时在设置中断开连接，断开即从钥匙串删除令牌。

5. 数据共享与出售

我们不会出售、出租或为广告目的共享你的任何数据。除上述你主动启用的即时通讯同步外，应用不向任何第三方发送你的个人数据。

6. 儿童隐私

本应用面向一般用户，不针对 13 岁以下儿童设计，也不有意收集儿童的任何信息。

7. 你的控制权

所有数据都在你本机。你可在应用偏好设置中重置全部数据，或直接卸载应用以清除所有本地存储。
