常见问题

  • "自动开启 macOS 专注模式"没反应？ 该功能依赖你在系统"快捷指令(Shortcuts)"中预先创建两个快捷指令：FocusFlow-Enable（动作：设置专注模式→开）和 FocusFlow-Disable（设置专注模式→关）。未安装时应用会优雅跳过并在面板顶部提示。
  • 付费音效点了没声音？ 付费音效首次使用需联网下载（来自 GitHub Releases），下载完成后即可离线播放。请检查网络连接。
  • IM 状态同步连接失败？ 在偏好设置 → 集成 中重新授权 Slack / Discord / Teams。授权失败时应用会静默跳过，不打断你的专注。
  • 如何清除全部数据？ 偏好设置中提供"重置全部"，或直接卸载应用即可清除所有本地存储。
