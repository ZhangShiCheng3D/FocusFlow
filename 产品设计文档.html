📖 产品定位

FocusFlow 是一个面向桌面生产力的 macOS 菜单栏工具，核心理念是 Local-First（本地优先）——所有核心功能离线可用，用户数据不离开设备，第三方集成采用最小化权限原则。产品使命：在用户坐下工作的瞬间，一键构建出沉浸式的数字工位氛围。

✅ FocusFlow 定位

  • 桌面生产力场景：写代码 / 写作 / 设计 / 学习
  • 「工位氛围构建器」— 环境音 + 系统状态一键切换
  • Local-First：离线可用，数据不离机
  • 安装包 < 30MB（ODR 按需下载其余音效）
  • 桌面端优先，菜单栏常驻，零切换成本

❌ 明确不做

  • 睡眠助眠场景（用户不会开着电脑睡前用）
  • 耳鸣治疗场景（属于医疗健康，需移动端）
  • 冥想 / 瑜伽场景（Headspace / Calm 已占据心智）
  • 移动端 App（资源聚焦 macOS，不分散精力）
  • 云端用户系统（不收集用户数据，不建账号体系）
🎯 目标用户

👨‍💻 程序员 / 开发者

开放式办公室噪音是头号生产力杀手。需要背景音屏蔽人声干扰，同时自动设置 Slack 状态为「专注中」。深度工作时还需阻断摸鱼站点。对隐私极度敏感，反感上传数据的 App。

🏠 远程工作者

在家办公缺乏「工作仪式感」。通过一键进入「工作模式」——环境音 + 通知屏蔽 + IM 状态同步 + 日历 Busy——划清工作与生活的界限。

🎨 设计师 / 创作者

需要大块不被打扰的创作时间。环境音帮助进入心流状态。全屏创作时仍需看到倒计时状态。习惯纯键盘操作。

📚 学生 / 研究者

期末复习或论文写作需要高强度专注。白噪音提升工作记忆效率。番茄钟帮助拆分学习时段，专注统计提供正向反馈。

📦 资源架构：On-Demand Resources 按需下载 v4.0
核心问题：20+ 高品质环境音若全部打入 Bundle，即使采用 AAC 256kbps，每个 3-5 分钟的音频文件约 6-10MB，总安装包体积将膨胀至 200-400MB。对于一款定位「轻量级菜单栏工具」的 App，这是转化率杀手。

📐 ODR 分层策略

Initial Install（< 30MB）：
· App 可执行文件 + UI 资源（~8MB）
· 3 个 Free Tier 音效：白噪音、雨声、咖啡馆（~18MB）

On-Demand 下载（用户触发时）：
· Pro 解锁后其余 17+ 音效按需后台下载
· 音效存储于 Cloudflare R2（S3 兼容，免费 10GB/月）
· 音频格式：AAC 192kbps，5-8 分钟无缝循环
· 下载后永久缓存至 ~/Library/Application Support/FocusFlow/

🔄 用户体验无缝化

点击未下载音效时：
· 显示环形进度条叠加在音效卡片上
· 边下边播（前 2 秒数据到达即开始播放）
· 下载速度预期：1-2 秒（单个音效 5-8MB，R2 全球 CDN）
· 下载完成后写入本地，后续离线可用

后台预加载策略：
· Pro 用户解锁时后台队列下载所有音效
· 用户浏览音效列表时预加载相邻音效
· 尊重用户网络环境（仅 WiFi 下自动下载，选项可配置）

☁️ Cloudflare R2 成本估算

存储（20 个音效，每个 ~6MB）：~120MB 总计，R2 免费额度 10GB → $0/月

下载流量（假设 1000 DAU，每人下载 10 个音效）：~60GB/月，R2 免费额度包含出站流量 → $0/月

实际成本：在达到 ~5000 DAU 之前，R2 完全免费。即使超过免费额度，成本也极低（~$0.015/GB）。

相比传统 CDN 方案，R2 的零出站流量费是最大优势。

🛡️ 隐私信任体系：Local-First by Design v4.0
核心问题：FocusFlow 申请的权限极其敏感——控制系统焦点、读取日历、接管第三方 IM (OAuth)、监控并阻断应用 (FamilyControls)。对于极其注重隐私的 macOS 目标用户（尤其是开发者），这份权限清单会引发强烈的卸载冲动。必须将隐私透明化作为产品的核心信任资产来构建。
🛡️
Local-First 承诺（Onboarding 首屏展示）：
· 所有专注数据仅存储在您的设备和私人 iCloud 中
· 无后端数据库，无用户账号体系，无行为追踪
· OAuth Token 仅通过临时中转服务握手，不长期存储
· 环境音全部本地处理，麦克风永不激活

📋 Onboarding 信任锚点

在 Onboarding 的第一屏（欢迎页之后），插入一个醒目的「隐私承诺」页面：

· 盾牌图标 + 大字「您的数据，留在您的设备上」
· 4 条 Local-First 承诺（见上方绿色盾牌区）
· 底部「了解更多」链接到官网隐私说明页
· 不强制用户停留，可一键跳过进入 App

🔐 各权限逐一释疑

在系统权限弹窗出现前（或设置页中），为每个敏感权限提供一行解释文字：

专注模式：「仅用于开关系统专注模式，不读取通知内容」
日历：「仅写入 Busy 时段，不读取您的日程详情」
ScreenTime：「仅屏蔽您指定的应用，不上报使用数据」
Slack/Teams：「仅修改您的在线状态，不读取消息」

🌐 OAuth Proxy 透明化

在 App 内设置页提供「连接详情」面板：

· 说明 Cloudflare Workers 仅做 OAuth 握手时的单次 Secret 注入
· Token 存储在本地 Keychain，Worker 不保存
· 提供 Workers 源代码链接（开源），用户可自行部署
· 「断开连接」按钮一键清除所有第三方 Token

🏆 App Store 隐私标签优势

基于 Local-First 架构，FocusFlow 在 App Store 的隐私营养标签可以做到极简：

· 「数据未与开发者共享」——无后端收集
· 「数据未用于追踪」——无分析 SDK
· 仅「诊断数据」可选收集（Crashlytics opt-in）

这与 Noisli（Web 端依赖 Cookie 追踪）形成鲜明对比，是重要的竞争差异点。

🆓➡️💎 Free vs Pro 分层策略

📌 Pin/分离交互（替代拖拽撕下）v4.0 调整

物理拖拽撕下（类似 Safari 拖出标签页动画）开发成本极高，且容易引发焦点丢失和 Z-Index 冲突。改为按钮式分离：

面板右上角提供 📌 Pin 图标按钮：
· 点击 → NSPopover 关闭，原地生成无边框 NSPanel 悬浮窗
· 再次点击悬浮窗的 Pin 按钮 → 恢复为菜单栏模式
· 支持 Always on Top + 跨桌面空间
· 完美覆盖全屏 App + 多显示器场景
· 实现成本远低于拖拽动画，交互更明确

⌨️ 全键盘导航 v4.0

目标用户是程序员和键盘重度用户，面板弹出后必须支持纯键盘操作：

🗺️ 用户核心旅程

1. 坐下，准备开工

双击菜单栏图标（或用自定义快捷键）→ 面板弹出。全屏用户可右键图标直接「开始上次专注」。

2. 键盘快速配置（或鼠标点选）

Tab 切换到时长（←→ 调整），Tab 到音效（Space 试听，↑↓ 调音量），Enter 开始专注。全程无需鼠标。或鼠标点击音效卡片 + 拖拽音量滑块。

3. 系统自动完成全套动作

✅ 环境音淡入播放
✅ macOS 专注模式开启（若已授权）
✅ IM 状态同步（若已授权；企业拦截则静默跳过）
✅ 应用阻断激活（App Store 版且已授权）
✅ 日历写入 Busy（若已授权）
✅ 倒计时出现在菜单栏（全屏用户可 Pin 出悬浮窗）

4. 深度工作中

倒计时实时更新。随时可用快捷键暂停/切换音效。全屏 App 下悬浮窗保持可见。若某服务未授权，对应步骤静默跳过，无任何弹窗。

5. 计时结束（或 Esc 手动退出）

✅ 环境音淡出停止
✅ 所有系统状态恢复
✅ 通知：「本轮专注 45 分钟 · 今日累计 2.5h」
✅ 数据计入统计看板（本地 + 私人 iCloud）

语言 & 框架

SwiftUI（macOS 14+ 目标，macOS 13 兼容），纯原生。代码量控制在 10000-15000 行（ODR 和 A11Y 增加复杂度）。

菜单栏 & UI

NSStatusItem + NSPopover（主面板）+ FloatingWidget（悬浮倒计时）+ NSPanel（Pin 分离控制台，无标题栏、圆角、可置顶）。无 Dock 图标。

音频引擎

AVAudioEngine 多轨混音。不播放时完全挂起。功耗红线：静默 CPU < 0.1%, 播放 CPU < 2%。ODR 音效与 Bundle 音效对播放器透明。

ODR 资源管理 v4.0

自建 ODR 系统：URLSession 后台下载 + 本地文件缓存 + 下载状态机。音效元数据 plist 描述所有音效的 R2 URL 和版本号。首次播放流式边下边播。

Cloudflare R2 存储

S3 兼容 API。音效文件按 sound_id/version.aac 存储。支持 If-Modified-Since 增量更新。免费额度 10GB 存储 + 零出站流量费。

隐私架构

无后端数据库。无用户系统。无分析 SDK（Crashlytics opt-in）。OAuth Token 存 Keychain。专注数据存 SwiftData + 私人 iCloud（NSUbiquitousKeyValueStore）。

A11Y 可访问性 v4.0

所有交互元素添加 .accessibilityLabel / .accessibilityHint / .accessibilityValue。键盘焦点链通过 .focusable + .onKeyPress 实现。支持 Full Keyboard Access 导航。

应用阻断

FamilyControls（App Store 版）。DMG 版降级为 NSWorkspace 通知监听 + 提醒弹窗。Phase 0 提交 TestFlight 验证 App Review 接受度。

OAuth + IM 集成

Cloudflare Workers 代理。Slack PKCE + Discord Bot Token + Teams Graph API。三层降级策略。Token 存 Keychain。Workers 源码开源可选自部署。

分发 & 更新

Mac App Store（主渠道，含 FamilyControls）+ DMG（辅助，提醒型降级）。Sparkle 2（DMG）。双版本功能差异在官网清晰说明。

💰 商业模型：核心买断 + 可选 API 维护费 v4.0
v3.0 遗留问题：$14.99 终身买断承诺「终身更新」，但 FocusFlow 并非纯本地软件——IM 状态同步依赖 Slack/Teams/Discord 的第三方 API，这些 API 会持续变（OAuth 策略更新、API 弃用、Token 格式变更）。随着新增用户减少，老用户的 API 维护成本将成为死穴。必须将商业模型拆分为「纯本地核心」和「第三方服务」两部分。

商业模型优势分析

抗风险：核心收入来自买断，不受 API 变动影响。

⚠️ 技术风险与可行性验证
核心原则：Phase 0 必须对所有高风险技术点进行 Demo 级验证。如果某项不可行，应在设计阶段调整方案。
#风险项风险等级问题描述验证方案降级/备选方案
R1 macOS 专注模式自动开关 🔴 高 无公开 API 供第三方静默开关系统专注模式。 Demo 测试 AppleScript / Shortcuts / DistributedNotification 三条路径。 改为引导用户手动开启。产品宣传调整为「辅助引导」。
R2 FamilyControls + App Review 🔴 高 ScreenTime API 定位为家长控制。苹果可能拒绝「生产力」用途。DMG 版无法获取 Entitlement。 ① Demo 测试动态屏蔽 ② 提交 TestFlight 占位包审核 ③ 测试 DMG 版能否获取 Entitlement。 重新定位为「数字健康」。DMG 版仅提醒。详见分发策略章节预案 A/B/C。
R3 OAuth Client Secret 安全 🔴 高 纯客户端无法安全存储 Secret。 搭建 CF Worker OAuth Proxy，测试延迟。Slack 同步测试 PKCE。 Slack 用 PKCE。Teams 无 PKCE 必须用 Worker。Worker 源码开源可自部署。
R4 AVAudioEngine 能耗 + 流式播放 🟡 中 常驻后台 + 流式边下边播增加复杂度。 测试引擎挂起功耗 + ODR 边下边播的缓冲延迟。 功耗红线：静默 CPU < 0.1%。边下边播缓冲目标 < 2 秒。
R5 Notch + Pin 悬浮窗 Z-Index 🟢 低 悬浮窗层级管理（全屏 App 之上、其他悬浮窗之下）。 测试 NSPanel 的 level 属性在不同场景下的行为。 NSFloatingWindowLevel 可满足大部分场景。
R6 TestFlight 审核：FamilyControls 用途 🔴 高 苹果可能拒绝非家长控制场景的 ScreenTime API 使用。 提交最小化 TestFlight 包，描述为「数字健康/屏幕时间管理」角度。 若被拒：① 调整为「数字健康」措辞 ② 申诉 ③ 放弃 FamilyControls。
R7 权限申请过多导致用户拒绝安装 v4.0 🟡 中 专注模式 + 日历 + ScreenTime + OAuth 的权限清单可能吓退隐私敏感用户。 Onboarding 隐私承诺页 + 权限逐一释疑文字 + 所有权限可选跳过。 若转化率受权限影响明显：将敏感权限（ScreenTime/日历）移到 Pro 解锁后触发。
Phase 0 Go/No-Go 标准：R1、R2、R3、R6 必须在此阶段得到明确结论。R7 通过 Onboarding 设计缓解，不做硬性阻断条件。

📊 市场验证数据

Noisli

白噪音赛道标杆。月访问超百万，$10/月订阅（年付 $120）。证明需求巨大且用户愿意付费。但 Web 形态摩擦 + Cookie 追踪是其弱点。

SlapMac

菜单栏音效 App，$7 买断，上线三天 $5000。验证菜单栏音频工具付费意愿。但功能单一，安装包 ~20MB（仅 5 音效）。

Monk Mode

菜单栏专注 App，$15 买断，4200+ 付费用户。验证专注自动化付费市场。无环境音、无第三方集成。

2026 菜单栏赛道趋势

Product Hunt 连续涌现菜单栏工具。共同特征：代码量小、维护成本低、$10-20 买断用户不敏感。A11Y 和隐私标签成为 App Store 推荐的新权重因素。
